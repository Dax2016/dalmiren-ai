# Security & Privacy Governance

## Privacy by Design
- **Zero API Key Leakage**: Keys remain exclusively in server-side environment files (`.env`).
- **Anonymized Data Transmissions**: Cloud AI providers receive no identifying personal details.
- **Audit Trails**: Every memory creation, edit, and deletion is recorded in `memory_audit_events`.
- **Data Deletion & Governance**: Parents maintain total control to clear local preferences, delete reflections, and reset account data.
